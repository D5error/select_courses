# Select Courses
### 介绍
这是从网上开源的大学选课插件代码，经过了一些修改，未经过实际测试，可能无法正常使用，**仅作为学习插件开发的目的**。

### 使用方法
1. 登录本科教务系统
2. 进入选课界面
3. 将要选的课添加收藏（可选课程预览）
4. 打开插件主界面
5. 输入选课数量（选到指定数量的课后插件自动停止运行）
6. 选择课程类型（如果需要同时选不同类型的课，如`专选`和`专必`的话，可以同时开两个网页，分别运行）
7. 点击`开始`按钮
8. 按`F12`或打开开发者工具可查看脚本运行相关信息
9. 如果需要停止插件运行，可点击`停止`按钮

### 导入插件
1. 打开edge浏览器 
2. 扩展 
3. 管理扩展 
4. 打开开发人员模式 
5. 加载解压缩的扩展 
6. 选择`select_couses`文件夹 
7. 启动插件

### 注意事项
1. 插件运行时尽量不要在除了edge浏览器之外的地方登录教务系统，否则会被系统踢出
2. 插件运行时可以挂后台，只要不关闭浏览器和网页即可
